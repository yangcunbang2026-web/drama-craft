Use the single [production workflow](references/workflow.md). Its six-stage table routes to complete instructions, 27 templates, repair decisions and a fictional example. Read only the stages needed for the current task.

Read the brief, authoritative script and real project state. Develop an idea, diagnose an existing script, resume the actual missing step or repair the affected part. Reuse reliable work and keep one record linking versions, references, source clips and edit ranges.

Fill templates with real project details. Treat T instructions as assistant tasks; compile tool-ready image, video or sound inputs separately. Follow project knowledge-access rules when a knowledge base exists; this skill also works without one or any other installed skill. Never invent files, timings, tool capabilities, costs or approval.
