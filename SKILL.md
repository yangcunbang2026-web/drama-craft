# Drama Craft

Use the single [production workflow](references/workflow.md) for the current stage. It contains directing decisions, 27 prompt templates, a fictional worked example, review criteria and repair paths. Users do not need to assemble multiple manuals.

Read the supplied brief, authoritative script and current project state first. Start from the actual input: develop an idea, diagnose a script, resume the real missing stage, or repair the affected part. Reuse reliable results and maintain one production record linking script versions, assets, shots, actual sources and edit ranges.

Fill prompt fields with the project's real details. Distinguish proposals, written plans, generated media, technical checks and normal-speed audiovisual approval. A source clip's duration is not an editing quota. Project requirements override examples; select tools and voice routes from capabilities actually available.

If a project knowledge base exists, follow its access rules and use current sources. This skill works without a private vault or a particular connector. Never invent asset paths, timestamps, tool access, costs or approval. Use only the user's authorized scope for uploads, paid jobs, installation or publication; finish independent work when a dependency is unavailable.
