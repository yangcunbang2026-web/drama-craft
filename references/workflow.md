# Drama Craft 制作流程

一份按任务展开的公开制作指南。主线为**剧本→资产→分镜提示词→小样与生成→剪辑声音→验收交付**；开工、返工和方法维护提供支持。已有成果直接继承，只补当前缺口。27套T指令保留在对应阶段，无需一次执行全部。

|阶段|交付与进入下步的条件|指令|
|---|---|---|
|[剧本](#剧本)|可制作逐场稿、准确对白、锁定内容与节拍|T01—T04|
|[资产](#资产)|本批角色／地点／道具版本和实看参考|T05—T09|
|[分镜](#分镜)|逐镜卡、接点、声音归属和完整生成正文|T10—T16|
|[生成与扩批](#生成与扩批)|连续小样、真实原片原声与可剪范围|T17—T18|
|[剪辑与声音](#剪辑与声音)|可编辑时间线、采用记录及声音层|T19—T23|
|[验收与交付](#验收与交付)|整片、工程、素材、版本与明确未核项|T24|

新任务或换助手接手时用T00，继续任务沿用已有记录；具体错误用T25／T26。T13—T16提供生成正文模板，其余T指令组织助手工作：先填写、适配，再把工具可执行的正文和真实输入交给模型，不混入检查表。省略不适用字段，不为填模板新增对白、动作或运镜。本文件不包含模型、媒体库或额度，也不保证一键出片。

## 开始与恢复

先读取brief、当前主稿和真实进度：作品用途、不可变内容、画幅语言、目标规模、风格、声音方案、现有资源、本轮交付与授权。想法先创作，现成稿先诊断，素材或工程从实际缺口恢复。可逆选择标工作假设，关键矛盾只询问影响推进的缺失信息。

### 执行边界与标准

项目明确规格优先；示例的镜数、时长和画幅不变成通用配额。原生对白、配音或其他声音方案依brief与真实能力选择，不能因一次失败擅自换路线。生成时先取得所需剧情声音，配乐留后期独立处理。

工作提案、文字已核、用户确认范围、媒体已取得、局部可用、可剪用、整场／整片自查与正式认可分别记。助手检查不代替作者确认；已有授权继续有效，不增加阶段口令。分别说明能看、能听的检查范围；抽帧或技术检测不代替原速声画检查，未检查的保留未核状态。

知识库可选：有连接时按项目权限选当前主源，过时记录和检索排名不决定有效版本；没有知识库也可按此文执行。未知路径、时码、能力、价格和认可不得编造。上传、付费、安装与发布依本轮授权；不可执行时完成独立部分并交具体缺口。

### 制作主单

沿用一套记录引用brief、主稿、资产、逐镜卡、任务原片和工程；不强制新建数据库或软件。每镜保留适用字段：

```text
镜号／场号／主稿版本；准确对白ID、原句与声音类型
剧情节拍、观众新知、人物目的、触发及回应
真实参考文件或ID、版本及各自职责
首态→关键变化→终态；位置朝向、视线、工作手和物件持有
景别机位、关键可见范围、轴线；固定或摄影起点／路径／落点
前尾后首、切点理由、声源归属与容量依据
本镜所需完整正文；源片长度与预计采用长度
实际任务、输入版本、原片原声、费用、采用区间、证据与未核项
```

交接核将实际采用的版本，不把旧建议表当已回填。未取得音视频不造字幕轴或剪辑区间；镜头数、候选源段数、付费任务数分别统计。

### 变更与恢复

改原句复核声音、嘴型、容量和字幕；改身份、空间或道具复核相关输入与相邻切口；剪空尾只复核节奏与声音边缘。缺失主源报告检索范围与未定位状态，不推断已删除，备份不自动升为当前稿；不相关缺件不反复列为开工条件。

**T00 总启动指令**

```text
材料：【输入】。请用 $drama-craft 识别当前阶段，继承brief与可靠成果，沿用同一制作记录。只交本轮所需的剧本、资产、镜头卡、提示词或媒体，不无条件重做全套。记录实际文件、检查依据、未核项与下一步；缺口只阻止依赖它的动作，结论区分设计、生成和验收。
```

## 剧本

先明确谁此刻要什么、阻碍、失败代价和为什么现在行动，再按选择与后果写场次。逐场给时间地点、人物、可见动作、现场对白、画外／设备声、独白和必要音效。人物知情、说话习惯与利益关系有依据，新增背景标创作建议。

现成稿定位原句检查动机、因果、知情、时间空间、对白、结果与可制作性，按授权最小修订。独立故事完成结局，分集悬念有铺垫和后续回应；关键证言、客观事实与推断分开，专业结论注明证明范围。

需改结尾时用T02比较线索揭示、选择困境或关系变化，写铺垫、最后可见画面与下集回应，只给适合本稿的备选；未采纳前保留原结尾。对白改写用T03，锁定原句不默认开放重写。

资源紧时比较三类制作量：必须看清的核心事件、可由已有声音／反应覆盖表达、可合并内容。说明节省与信息损失，保留关键选择和因果；不能把没呈现的行为登记为已完成。

### 场面设计

用企图—抵抗—尝试—回应—变化组织可见过程。谈话看判断与控制，交接看状态与持有权，核验看材料、操作、结果和边界，抵达交代新任务，群戏交代关注与在场关系。动作服务这些变化，翻纸和眨眼本身不证明有戏。

### 节拍与轻重

每拍记录原文范围、触发、前后变化、必看信息、关注对象和停留理由。冲突、升级、情绪转折和反转是寻找节点的提示，不要求每场凑齐，也不要求一拍一镜。平静对白仍可能承担重要行动。

全片看任务链，场内看局势，镜内看表演。停顿要有理解、选择或抵抗；时长依实际对白、动作、读取和反应需要安排。等长未必错误，故意凑长短也不改善节奏。固定秒数只能作预算，取得声画后再定采用。

**T01 从想法写逐场稿**

```text
创作任务：【核心想法及资源限制】。建立人物当下目标与不能轻易解决的障碍，让选择带来代价并形成结局。写出场景、动作和准确发言的逐场正文，区分现场声、设备声和心理声音。附需制作的人物地点物件以及仍是假设的设定。
```

**T02 诊断与最小修订**

```text
阅读【剧本版本】。找出会使观众误解或失去兴趣的动机、因果、知情和呈现问题，以场号或原句定位，给最小改动及其影响。原设定【保留项】不得被提案悄悄改写；只有已授权部分直接写修订正文。
```

**T03 对白与连续性复核**

```text
检查【对白、人物目的及相关场次】的容量与连续性。逐句说明声源、意图和动作交叠点，文本估计与音轨实测分开。锁定长句比较延长、覆盖或分段；授权改写时交符合人物口吻的自然短句及信息对照，改独白须符合既定路线，不加速塞词。核人物知情、时间、状态与道具连续，给具体修法和下游影响。
```

**T04 场面导演指令**

```text
根据【场面与锁定设定】先列节拍：原文范围、触发、人物判断或行动的前后变化、观众要看见什么、关注对象与停留理由。连接企图、抵抗、尝试和结果；没有原文依据的爆发或反转不添加。一拍可由持续镜头或必要覆盖承担，不按台词逐句配镜。说明表演和对白如何并行，再给关键状态与下一段入口。
```

## 资产

从主稿提取本批角色、地点和道具，复用可靠文件，基础身份与湿衣、伤口、破损等状态分版本，不把状态变化误建成新角色。文件存在、实际看过、适合本镜分别核。

人物固定脸、年龄、比例、发型衣装、配饰和自身左右，只做会使用的角度／表情。道具固定形状、尺度、材质、识别点和关键文字，另记开合及持有者；独立参考无人物手。婴儿或动物用T07／T13适配支撑与接触：婴儿承托符合年龄，四足动物保物种骨架，不套成人中性站姿。

### 空间与光线

锁门窗家具、路线、摄影可用区和世界光源；房间方位、画面左右、身体左右分开。每个角度核脸、手物、肩桌遮挡与起身抬手的占位，关键接触检查中间过程而非仅首尾。

身份图保身份，空间图保几何，光色图保受光与构图，道具图保当前状态；排除过时姿势、错误座位和未来结果，冲突参考先取舍。反打重算可见面与受光面，不镜像房间或照搬画面左侧光。关键脸与证据可读，画幅改变重新设计取景。

光线写方向、软硬冷暖、人物与背景亮度；导演姓名、机身名和质量词不替代画面要求。不预设雾雨、颗粒或强烈色调作为所有故事的风格。

首次定风格或风格冲突时用T09提炼色彩、光源、材质、对比、年代与造型，给人物／地点／道具共用描述，同时保留不同身份；已有约定直接继承。资产记录ID、出现的场次、基础版／状态版、实际文件、用途和待补项。

**T05 角色身份参考**

```text
角色参考任务：【人物定义及所需角度】。身份取自【已获使用权的参考或新设计】，保持年龄、结构、发型、衣装与不对称特征。若做三视图，以同一人的真实转向展示完整身体，统一比例和中性姿态。只创建这次需要的视角。
```

**T06 表情服装与局部状态**

```text
状态变化：【角色及变化位置】。以【身份参考】为底，仅改变指定表情、衣装或局部状态，其余特征保持。说明变化在故事中的原因、允许修改范围及完成后要对照的区域。心理独白用途不要生成发言嘴形。
```

**T07 场景基准与新机位**

```text
空间任务：【地点、当前时刻和观察位置】。先说明出入口、窗、家具、物件和行走区域的关系，再写该角度可见及遮挡内容。根据固定世界光源安排受光，换角不镜像房间；未知区域作为设计问题列出，不假装已有参考。
```

**T08 道具基础与状态**

```text
物件任务：【物件身份、用途及当前状态】。按必要视角固定轮廓、材质、尺度与辨识细节，单独制作，不加入手或人物。需要的准确文字使用【可控制的美术方案】。持有者另记，状态变化与基础版本能够相互核对。
```

**T09 摄影与照明修订**

```text
依据【故事气质、实际参考和视觉约定】，需要时先交人物／地点／道具共用风格描述，已有约定复用。修图时定位【实际画面】的摄影问题，保留身份、几何和状态，只改指定范围。写清主体大小位置、关键手物可见范围、机位、注意落点、世界光源及明暗关系，交完整正文和对照检查，不用风格名或质量词代替可见改变。
```

## 分镜

按观众进入时已知什么、最终须理解什么，先找节拍，再选观察对象、取景、切点和源段。关系景保互动与物件控制，中景／过肩保工作与手势，近景看判断，细节看可读线索，主观符合观察者位置；情绪标签不固定对应景别。

若brief明确镜数和时长限制，T10／T17复算每镜与总时长。只有任务明确要求九镜15秒、每镜1—3秒时才检查这些数值，其他作品不套用。

### 分镜与切点

每切有信息、回应、动作承接或关系变化。并看前尾后首，核位置、站坐、朝向、视线、工作手、持有物、动作进度、运动方向、光源、注意区和声音。动作切口接同一次行动，不重新准备；同角度微裁易跳动，比较延续或有意义换角。越轴需可读移动或重新建立关系，不靠镜像。

摄影写起始构图、运动原因、路径、终点和停止触发；固定同样需要表演。物理移动、变焦与后期缩放分开，数值设计须服从真实控制能力，验收看显露、视差、保留范围和落点。

### 完整任务与源段

每段定原句与说话者、起态、动作、可剪终态、下段接法、声音来源和容量依据。文字估计、占位朗读、自然读演与真实原声不是同一证据。长任务比较真实长输出、动作点换角、有效覆盖或续接；同机位多条会重置姿态、呼吸和声音，不能先称无缝。

源片容器不决定故事节奏，不为省次数在短源片内跳切多个独立镜头，也不把简单接触拆成多次无用任务。覆盖属于同一时刻状态且有真实声源；锁定原句不擅删、改类型或加速。

### 表演与声画

人物保持持续任务，信息触发观察、停手或新选择，动作对白可并行；反应不早于信息。抽象情绪落为当前取景看得清的主要行为，不堆微表情或固定半秒。摔物、掉信件等新增行为须有剧情依据。

现场发言者说准确原句、匹配口型，听者不跟嘴；画外或电话明确声源和在场关系，远端人物不凭空入画；设备回放由设备发声，现场本人不代说；内心独白嘴闭合，一条完整轨跨镜；无对白动作不新增句子。混合源段按事件分别写嘴部要求，保留主稿中的声音限定词。

若brief选原生声画，准确现场句、画面和口型同次取得，保留合格原声。用同角色不同情绪短段相邻听审跨源声线；表演变化不直接判换人，固定提示、种子或身份图不保证锁声。

### 图片与视频提示词

编译顺序为实际参考及职责、单一状态或主要过程、动作主体与声音、摄影光线、不变项及具体排除项。图片只取当前起态与静态机位，视频只写本段触发的过程；不能把动态路线和终点粘进首帧。先用文字说明首态、关键态和终态，高风险才补必要图，尾图控制取决于工具能力。

多栏状态要一致，不能同时递腕又称双手未递、物件已带走又留桌。关键标签用正确美术／合成与可读构图，不以乱码承担信息。

九宫格只作按需静态预演：按已定镜序每格画起态，单次多格不稳时分图再排；其他规模不为凑九格改镜数。预演可查构图和关注，不能证明运动、嘴型或声音已过关。

**T10 逐镜导演卡**

```text
依【本批剧本、节拍和交付规格】建立逐镜卡：每镜承载哪次变化，为什么看此人或此物，取景保留什么，在哪里切以及时长依据。给准确原句、声源与嘴部归属、首态、动作、终态、摄影和相邻承接。情绪不自动对应某种景别，镜头不按台词均分；未实测音频只写预算。合并无职责重复，核真实参考和关键行为可见性。
```

**T11 相邻切口复核**

```text
检查切口【前镜尾与后镜首】。核位置、目光、手物控制、动作阶段、运动方向、光源和声音，判断观众能否连续理解同一事件。给可执行的切点或后镜起态建议；缺关键过程就列补片需求，不用无关画面遮住。
```

**T12 源片分段与声音承接**

```text
为【长表演和准确原句】比较当前工具确实支持的连续输出、换机位、有效听者覆盖和续段方式。每个候选段注明起终状态、句子范围、声轨来源及接法。若呼吸、姿态或声线无法可靠延续，明确测试风险和替代覆盖。
```

**T13 单镜首帧正文**

```text
单帧任务：【镜号】。引用【实际参考及各自用途】，只呈现【当前姿态与手物状态】。明确观察位置、画内范围、关注点、光源效果和画幅。保持【不变条件】，排除【本镜具体风险】；动作结果不应提前出现在起始图。
```

**T14 原生声画或本作已定路线的视频正文**

```text
连续视频任务：【镜号及真实输入】。由【正确主体】在【触发事件】后从【开始状态】完成【主要行动与回应】，收在【可接终态】。摄影【路径与起终构图或固定】，准确声音【类型、发言者与原句】，动作发言交叠点【节点】。保持已定资产，不加其他对白、音乐或字幕；长度依工具真实能力。
```

**T15 尾态正文与使用方式**

```text
终态设计：【当前镜头及动作】。写结束时的人物朝向、手物关系及下一镜入口，说明变化与不变项。平台支持且已核用法时才把尾图作为控制输入；不支持时交单首帧加动作落点正文，尾态仅作结果对照。换角重新构图，尾图正确不证明中间过程已通过。
```

**T16 闭嘴独白与连续音轨**

```text
心理声音任务：【完整独白及镜头段】。分别给闭嘴画面的信息变化和独立连续音轨要求，不让每个镜头从头念同句。没有音频时保留容量估计，获得真实音轨后再对区间，现场对白不能被此方案自动替换。
```

## 生成与扩批

先核本批原稿原句、实看参考、动作与声音接点、平台能力、档位和费用。已有任务查状态，报错区分是否建任务、是否入队、是否扣费；队列满不记成功，旧余额不当实时数据。

无生成工具时交实际参考、已填正文、受支持设置和原片回传要求，由用户手动生成，回片后走T18。平台不支持既定声音路线时报告具体缺口，不擅改静音或后配音。

小样包含一次完整企图—回应及一个有职责切口，覆盖当前核心风险，原生声音方案加入同角色跨源比较。孤立漂亮画面或手部测试不代表整场观感。

按原片原声可开、整条原速听看、输入与第0帧／关键过程／末态对照、相邻镜连看、状态与区间记录的顺序检查。抽帧、转写和解码是辅助。相同缺陷在未改设置下重复，先改输入／设计或核能力，不持续抽卡；费用沿用授权。条件通过才扩相应范围，可用几镜及时入粗剪。

**T17 提交前与小样执行**

```text
小样计划：【制作卡、真实参考与核心风险】。先核现有任务及工具能力，选最少但能体现企图、回应和接点的连续样段；如需原生声画，比较同角色跨段声线。只在授权预算内提交，保存输入、任务、输出和费用，再决定是否扩量。
```

**T18 源片结果验收**

```text
验收【输入、本镜要求、准确原句和原片】。先原速听看全段，再用关键帧或转写定位。分别判断身份、状态、完整行动、取景、对白、嘴型和声音身份，给实际可用范围与退回原因。无法检查的保持未核，局部正确不升级为整体完成。
```

## 剪辑与声音

按真实文件或唯一ID选素材，模糊名称核内容与匹配数；优先沿用工程，无工程时用真实可用工具新建时间线或可继续修改的脚本，说明编辑方式与限制。记录镜号—原片—源入出点—时间线位置，保留原片原声，缺镜和占位明确标记。

先接因果和任务，再看表演接话，后查空间手物与声音。删无信息头尾、重复准备和空等，不能剪掉关键词或关键接触。错主体、错句错嘴、缺动作回相关上游修，裁切和效果不补不存在的行为。

### 声音与换场

对白／设备／独白守归属与完整音节，空间底声同地点连续，拟音对齐真实事件与远近，叙事提示声有依据，配乐按整场或发布段安排。J切是下一画面声音提前，L切是上一画面声音延续，按真实表演选用，不能盖错嘴。

跨场连上场问题和下场任务，补必要时间地点。不要为换场临时新增电话，不把不同地点同类道具伪装成连续交接，声音预入不能提前泄露剧情信息。

### 配乐与混音

音乐先明确剧情作用、能量、编制、让位与收束，独立于视频生成制作；重要信息可撤乐。比较音乐贡献时保持同画面与接近听感，避免把多变量改善归因于一项。

人声优先，再检查底声、拟音、音乐让位与切边，手机外放和耳机试听；有真实测量才写响度，降噪不能损声音身份。字幕按需核原句、实际音频、阅读速度及安全区，调色先匹配同场肤色、曝光、白平衡和世界光源。滤镜不修受光矛盾或缺失细节。

**T19 粗剪与接话**

```text
用【真实可用片段】在【既有工程或可用工具新建的时间线／脚本】连接完整事件。记录原片入出点与时间线位置，保留合格声轨、标明缺镜。先接行动回应，再删无信息头尾；动作切口接进度，不漏接触、重复准备、加速或损伤台词。交可继续修改的工程／脚本及可播放粗剪，说明编辑方式与限制并重播检查，不用效果遮错。
```

**T20 底声与瞬时拟音**

```text
音效任务：【空间或接触事件】。声明声音来自哪里、距离和方向、质感、持续范围及对应实际动作。持续层跨同场镜头，瞬时层落在真实接触上；分轨输出，不额外生成台词、歌声或音乐。未知时码以事件标记，不编造测量。
```

**T21 完整独白铺轨**

```text
独白铺设：【真实音频与连续画面】。保留一条完整声音，按实际区间跨镜使用，画面角色闭嘴且有新信息。同句不能重复或叠轨。超过段落容量时先提出结构调整，文本改动受创作授权约束；缺音频时只输出计划。
```

**T22 整段原创配乐**

```text
配乐简报：【完整段落、真实长度与情绪转折】。描述编制、能量发展、对白让位和结束方式，再写原创纯音乐生成要求。无人声或歌词，不借用现成旋律，不每条源片重开。实际长度、控制能力和使用许可按所用服务核实。
```

**T23 混音字幕与调色检查**

```text
按【真实工程与交付brief】检查并在授权范围内修正台词、角色声线、底声、拟音及轨道边缘；音乐不压关键词，无爆音和突断。实测与试听分开，外放／耳机未听项标明。字幕核人名、说话者、断句与实际音频，交所需文件／轨道，读得完并避安全区和关键脸手物；无音频只交待对齐文本，不造时码。匹配曝光、肤色、白平衡与光源，不压黑遮错，修改后整段重播。
```

## 验收与交付

文字、实际图、完整源片、剪辑场面和整片分层检查。先正常播放看懂听清与自然，再逐帧定位；解码、黑帧／冻结、转写和响度分别报告。先修剧情／交付阻项，再修体验问题，未证实的新建议保持待验。

交付范围内能找到主稿、资产版本、提示词、任务费用、原片原声、采用关系、工程、最终文件、修改和未核项。规格依brief，低清源放大仍标测试，自查、正式认可和公开发布不相互代记。

交接工程时收集素材，使用相对目录或工程打包功能，保存文件／版本映射；在交付位置重开检查缺链并实播成片。不要只交本机路径清单，素材和声音的使用权限仍需独立核实。

**T24 成片与工程验收交付**

```text
交付审查：【实际作品、工程和有效brief】。将叙事、人物空间、动作摄影、准确对白嘴型、声音及素材完整性逐项对照，问题带位置、证据、影响和修法。检查技术规格及工程可打开性；缺少原速检查的项目不写通过，交实际路径与版本。
```

## 返工

先定位问题属于剧本、资产、分镜、正文、平台、剪辑或声音，修最小但完整的事件。共用错误先修共用输入，结构失败明确重设计。

|现象|检查与修复方向|
|---|---|
|慢、僵、空等|节拍、持续任务、信息触发、对白动作是否串行；修回应和有效区间，不整体倍速|
|突然紧裁、反打换空间|关注入口、机位轴线、布局与光源；重建有职责取景，不只叠化或虚背景|
|错主体、手物漂移／穿模|输入绑定、左右手、状态和中途支撑；补完整接触，不只验首尾|
|首帧提前完成|状态是否混入过程、摄影路线或终点；重编一个瞬间并核输出第0帧|
|错句、错嘴、换声或接不起来|原句、声源、自然起收音、姿态重置、接点和真实控制能力|
|线索不可读|内容、美术、尺寸透视、读取时间和发现者；不以乱码交差|
|仅缺环境或动作声|画面原声已合格时只补必要声音并核接点|
|技术过却没戏|回查人物目的、关系变化、注意与完整表演|

补片覆盖所需准备、接触、改变和可接终态；不要只替坏帧造成跳断，原生对白不拼不同身份碎音节。复查目标、原优点退化、前后切口和实际采用。删目标动作或紧裁遮错只记部分可用。保存版本、位置、输入、修改、费用及结果。

**T25 局部修图**

```text
图像局修：【原图、错区和目标】。限定可改内容，保护身份、构图、布局和光线等可靠部分。按真实工具方式提供修订正文或需要的区域输入，不能虚构遮罩已用。结果既查目标修复，也查脸、衣装和几何是否退化。
```

**T26 返工执行与复核**

```text
返工任务：【问题、版本和实物证据】。先判故事、资产、设计、生成、编辑还是声音原因，再确定最小但完整的替换事件范围。给保留项、修改项、实际指令及前后镜复核，结构问题可以重设计。裁掉目标行为后只记剩余可用范围，费用不超授权。
```

## 参考与维护

### 参考如何落实

每次用参考解决具体问题，记来源、时间位置、实际检查方式、可见机制、项目采用与验证方式。未听声音不推配器、声线或精确声画切时；视觉采样和自动切点不当正式采用区间。借方法，不复制他人角色、台词、音乐或媒体。

### 方法更新

有证据且适用的保留，暴露缺陷的改进，重复的合并，被覆盖的退役，未验证的留候选。记录现象、证据、修改、实际结果、用户反馈与条件；一次认可不证明各变量单独有效，一次例外不变永久禁令。更新对应正文与受影响记录，不再复制第二套手册。

### 完整交接示例

这是新写的虚构示例，未使用真实项目台词，也没有生成媒体。地点是相机维修店，顾客米朵持取件单，店员阿棠隔柜核对封袋。

#### 剧本输入

米朵把取件单举到柜沿：“这是我的取件单。”阿棠看单，再看封袋标签：“单号是二十六，袋上是二十九。”米朵收住伸向封袋的手：“那先别拆封。”封袋始终由阿棠控制，未被拆开。

#### 资产与场面依据

CHAR_A为阿棠，CHAR_B为米朵，LOC_COUNTER为店内柜台。PROP_RECEIPT标二十六，PROP_BAG标二十九，正确标签需单独制作或合成。此刻只有文字设计，身份与场景图片均待制作或绑定；这些ID不是已存在文件。

双方任务由取物转为核对差异。关系中景说明谁持单、谁控制封袋；核对镜头让单、标签和店员脸具备读取机会；反应镜头承接顾客主动停止伸手。不是每句话都必须独立一镜，最终覆盖按真实容量和可读性选择。

#### DEMO-02导演卡

目标：让观众明白店员发现编号不符，暂时不能交物。首态为店员目光落在单上，封袋在柜台内侧、其左手旁；关键态看向袋签并比对；终态抬眼告知顾客。摄影在柜台南侧越顾客肩看店员，中景保留单、袋签与脸，固定机位。顾客不抢袋，袋不拆封。准确原句只由店员说一次：“单号是二十六，袋上是二十九。”容量未实测，不给最终秒数。

#### 首帧正文

横屏16:9，维修店柜台南侧越米朵肩看阿棠的中景。阿棠目光落在柜沿的取件单上，尚未转头看袋签。封闭封袋放在柜台内侧、阿棠左手旁，米朵的手还在自己一侧。单据和标签预留可正确合成的区域，前景肩不挡关键阅读范围。柜台、出入口和顶灯位置保持本场设定，人物身份衣装待按实际参考绑定。只画当前一个瞬间，不拆封、不递袋、不加字幕水印。

#### 视频正文

从已核首帧开始，阿棠看完取件单，再将目光移到自己左手旁的封袋标签，随后抬眼对米朵自然说：“单号是二十六，袋上是二十九。”米朵只听、不跟嘴；封袋始终在阿棠控制范围，保持封闭。摄影机固定，保留核对动作和人物脸，数字标签另用已校对美术。需要纸张轻触声与连续店内底声，无音乐、烧录字幕或其他台词。若本作采用原生对白，声画和对应口型同次输出；输入和平台未核前不提交。

#### 验收

先原速听看，核准确数字、说话者、嘴型、语速与声线；再核目光是否真从单到标签、封袋是否始终未开、顾客是否提前抢袋。接反应镜时保留“得知差异后停止伸手”的因果。生成文字乱、不具备可读美术、嘴型失配或关键动作缺失时，不能因画面漂亮就通过；只修受影响内容，实际采用区间待原片出现后填写。
